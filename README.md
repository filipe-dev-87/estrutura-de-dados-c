# 📚 Estrutura de Dados em C

Este repositório contém implementações e exemplos práticos de **estruturas de dados** desenvolvidas na linguagem de programação **C**.  
O objetivo é servir como material de estudo e consulta para quem deseja aprender ou revisar conceitos fundamentais de estruturas de dados.

## 🔹 Conteúdo do Projeto

As implementações estão organizadas em tópicos, com exemplos e exercícios:

- ✅ **Vetores (Arrays)**
- ✅ **Listas Encadeadas**
- ✅ **Pilhas (Stacks)**
- ✅ **Filas (Queues)**
- ✅ **Árvores**
- ✅ **Grafos**
- ✅ **Tabelas Hash**
- 🔜 **Exercícios práticos**

## 🛠️ Tecnologias Utilizadas

- Linguagem **C**
- IDEs sugeridas: **Code::Blocks** ou outra de sua preferência
- **Git/GitHub** para versionamento
